# 中文实例多账号首版实施计划

## 目标

只升级现有中文 `jsys` 实例，使同一公司下的不同分公司账号拥有彼此隔离的活动工作区；保留全部历史数据和既有公开链接。独立英文 `jsys-en` 实例完全不改动。

## 首版范围

- 公开注册：任意邮箱可注册，邮箱和密码加工作区名称；注册成功立即启用并获得空工作区。
- 一个精确、区分字母大小写的邮箱值只能拥有一个分公司账号。
- 每个分公司账号首版只有一位 Account Owner；账号之间不能查看或操作彼此的活动、报名、抽奖、导出和业务日志。
- Account Owner 可修改工作区名称和密码，不能修改邮箱；不提供自行注销。
- 独立的 Platform Administrator 入口，只能查看工作区名称、邮箱、状态，并执行禁用、重新启用和直接设置新密码；不能查看任何业务数据或业务日志。
- 所有页面默认中文，并提供中英文界面切换按钮。浏览器记住自己的选择；只翻译系统文案，不翻译任何用户填写内容。
- 账号、登录、设置、活动、报名、抽奖、作废、导出等操作保留审计记录。
- 历史数据迁入工作区名称为“`中国账号`”的中国账号；原报名链接、二维码和结果页链接继续可用。

## 明确不做

- 不修改、合并或迁移 `jsys-en`。
- 不做国家/地区字段、国家唯一性、公司邮箱白名单或注册审批。
- 不做成员邀请、多管理员、角色权限体系、客户自助注销、邮件找回密码、短信通知或邮件通知。
- 不保存账号语言偏好、活动语言偏好或翻译后的用户内容。
- Platform Administrator 不获得业务数据查看、导出、抽奖或业务审计权限。

## 逻辑数据边界

| 对象 | 首版必须保存的关键信息 |
| --- | --- |
| 分公司账号 | 工作区名称、状态、创建时间 |
| Account Owner | 精确邮箱值、密码哈希、所属分公司账号 |
| Platform Administrator | 独立身份、密码哈希、内部入口权限 |
| 会话 | 身份、创建与失效时间、撤销状态 |
| 业务数据 | 既有活动、报名、中奖、导出、操作记录，加上所属分公司账号 |
| 审计记录 | 操作者、目标、时间、操作结果、所属账号边界 |

SQLite 是中文实例的唯一运行时持久化存储。所有受保护的查询和写操作必须从已认证身份取得分公司账号，再按该账号过滤；不能仅依赖前端隐藏按钮或前端传入的账号 ID。

## 迁移与上线顺序

1. 上线前备份现有中文实例的 TSV 数据文件和部署配置；英文实例不进入迁移范围。
2. 首次启动时，从部署配置取得中国账号 Owner 的邮箱和初始密码，以及 Platform Administrator 的邮箱和初始密码。
3. 创建 SQLite 数据库、账号与权限基础数据；中国账号工作区名称固定为“`中国账号`”。
4. 在一个事务性迁移步骤中导入活动、报名、中奖、导出和操作记录，并把它们全部归属中国账号；保留原活动和公开 URL 标识。
5. 迁移完成后验证数据数量、抽样打开旧链接、使用中国账号 Owner 登录，并确认 Platform Administrator 看不到业务数据。
6. 验收完成前保留原 TSV 备份，不删除源文件；若迁移校验失败，停止切换并从备份恢复，而不是混用两套写入存储。

## 开发顺序

1. **持久化与迁移基础**：接入 SQLite，建立账号、身份、会话、审计和业务归属关系；实现可重复检查但只执行一次的历史迁移。
2. **认证与服务器授权**：实现注册、登录、登出、7 天会话、密码哈希、禁用/重新启用、密码重置和会话立即撤销；把现有全局管理员校验替换为账号边界校验。
3. **分公司 Owner 后台**：登录、注册、设置页，以及活动、报名、中奖、导出和业务审计的隔离列表与操作。
4. **Platform Administrator 后台**：独立入口、账号列表、状态切换、直接设置新密码和账号管理审计；不接入业务查询接口。
5. **公开页面与语言按钮**：保持已有公共 URL 行为；当账号禁用时关闭其报名、结果和大屏页面；为所有页面加入浏览器本地的中英文系统文案切换。
6. **回归与部署验证**：完成迁移演练、跨账号越权测试、禁用测试、旧链接测试、语言内容不变测试，以及英文实例未变化检查。

## 最小验收场景

1. 用两个不同邮箱注册 A、B 两个账号；A 无法列出、读取或操作 B 的任一活动，即使知道 B 的活动 ID。
2. A 创建活动并完成报名、抽奖、作废和导出；审计记录显示实际操作者，B 不可见。
3. Platform Administrator 只能看到 A/B 的工作区名称、邮箱和状态，无法读取活动、报名、中奖、导出或业务审计。
4. 禁用 A 后，A 的登录会话和全部公开活动页不可用；重新启用后恢复，数据没有删除。
5. 迁移后，中国账号能看到历史数据，原有报名/结果链接仍有效。
6. 任意页面切换中英文后，系统按钮和提示语改变，活动标题、题目、选项、工作区名称和报名答案保持原样。
7. `jsys-en` 的代码、数据和服务配置均未发生变化。

## 开始编码前仍需准备的部署信息

- 中国账号 Owner 的真实邮箱与初始密码。
- Platform Administrator 的真实邮箱与初始密码。
- 生产服务器上的 SQLite 数据库备份位置与迁移执行窗口。
- 内部 Platform Administrator 入口地址的实际路径，仅内部保存，不在普通登录页展示。
