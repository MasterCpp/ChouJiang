# 02 — 分公司账号注册与业务隔离

**What to build:** 让分公司 Owner 用邮箱、密码和工作区名称立即注册并管理自己的空工作区；任何账号均无法查看或操作其他账号的业务数据。

**Blocked by:** 01 — 中国账号迁移与 Owner 登录基线.

**Status:** ready-for-agent

- [ ] 任意邮箱可立即注册一个账号，邮箱大小写按精确值区分，工作区名称与密码按确认规则校验。
- [ ] 新账号可创建和管理自己的活动，但不能读取或操作另一个账号的活动、报名、中奖、导出或业务审计。
- [ ] Owner 可修改工作区名称和密码，不能修改邮箱；相关操作保留审计记录。
