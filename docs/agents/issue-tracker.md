# Issue Tracker

This repo uses local markdown issues.

Issues live in:

```text
.scratch/issues/
```

Each issue should be independently understandable and include:

- Goal
- Background
- Scope
- Acceptance criteria
- Implementation notes
- Status

Use local files instead of GitHub Issues unless the repo is later moved to a GitHub workflow.

Recommended status values:

- `needs-triage`
- `needs-info`
- `ready-for-agent`
- `ready-for-human`
- `wontfix`
- `in-progress`
- `done`

When implementing, read `CONTEXT.md`, then the relevant issue file.
