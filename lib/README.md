# Runtime dependency

`sqlite-jdbc-3.53.2.0.jar` is the Xerial SQLite JDBC driver used only by the upgraded Chinese `jsys` instance.

- Source: Maven Central, `org.xerial:sqlite-jdbc:3.53.2.0`
- Integrity file: `sqlite-jdbc-3.53.2.0.jar.sha1`
- The independent `jsys-en` service remains on its existing classpath and does not use this dependency.
